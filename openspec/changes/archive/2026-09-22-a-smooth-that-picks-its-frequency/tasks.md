- [x] 1.1 Name the three in `clayspace-model` — the form, the detail alone, the form with the detail — with the third as the default, and say in the type why the split is representational rather than a strength setting.

## 2. Reach the entry point the table already names

## 3. The choice, where a sculptor makes it

## 4. What an agent reads and sets

- [x] 4.1 Report the mode in the tool section of `state`, on a hierarchy and absent elsewhere.

## 5. Measured, not argued

- [x] 5.1 Deposit detail in a pass over a hierarchy and subtract it against an otherwise identical one, so "did the detail survive" is a subtraction rather than a guess about which part of one surface was which.
- [x] 5.2 Assert both halves of the default mode: the detail is still at its own height *and* the form underneath moved — either alone passes for a smooth that did nothing.
- [x] 5.3 Assert the contrast at the form frequency, so the mode that removes the pores stays reachable and stays honest.
